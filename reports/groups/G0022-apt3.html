2. Quem é

APT3 is a China-based threat group that researchers have attributed to China's Ministry of State Security. This group is responsible for the campaigns known as Operation Clandestine Fox, Operation Clandestine Wolf, and Operation Double Tap. As of June 2015, the group appears to have shifted from targeting primarily US victims to primarily political organizations in Hong Kong.

10. Hipóteses de hunting

Se APT3 estiver no seu ambiente, estas são as perguntas a fazer aos seus dados (fontes de log segundo as estratégias de detecção do MITRE ATT&CK).

  1. T1036.010 Masquerade Account Name — Detects adversary behavior where a newly created or renamed user account closely resembles existing service or administrator accounts to blend in and avoid detection. Common patterns include prefix/suffix modifications, homoglyphs, or use of names like… Dados: WinEventLog:Security (EventCode=4720), windows:osquery (User enumeration with creation/last modified timestamps).
  2. T1104 Multi-Stage Channels — Initial process initiates outbound connection to first-stage C2, receives payloads or commands, then spawns or injects into a second process that establishes a new outbound connection to an unrelated destination (second-stage C2). Dados: WinEventLog:Sysmon (EventCode=3, 22), WinEventLog:Sysmon (EventCode=1).
  3. T1110.002 Password Cracking — Use of hash-cracking tools (e.g., John the Ripper, Hashcat) after credential dumping, combined with high CPU usage or GPU invocation via unsigned binaries accessing password hash files Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Security (EventCode=4663, 4670, 4656), WinEventLog:Sysmon (EventCode=11).
  4. T1069 Permission Groups Discovery — Detection of adversary enumeration of domain or local group memberships via native tools such as net.exe, PowerShell, or WMI. This activity may precede lateral movement or privilege escalation. Dados: WinEventLog:Security (EventCode=4688), WinEventLog:PowerShell (EventCode=4103, 4104, 4105, 4106).
  5. T1546.008 Accessibility Features — Defenders can observe suspicious replacement or tampering of system accessibility binaries (e.g., utilman.exe, sethc.exe, osk.exe) and anomalous modifications to registry keys used to redirect accessibility programs (such as IFEO keys). Additionally,… Dados: WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=13, 14).
  6. T1027.005 Indicator Removal from Tools — Detection of known tools or malware flagged by antivirus, followed by a near-term drop of a similar binary with modified signature and resumed activity (execution, C2, or persistence). Dados: WinEventLog:Application (EventCode=1000), WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=11).
  7. T1098.007 Additional Local or Domain Groups — Detects unauthorized additions of users or machine accounts to privileged local or domain groups (e.g., Administrators, Remote Desktop Users). Dados: WinEventLog:Security (EventCode=4728, 4729, 4732, 4733, 4756, 4757).
  8. T1090.002 External Proxy — Unusual process (e.g., rundll32, mshta, wscript, or custom payloads) initiates network connection to external IPs/domains that proxy C2 traffic, often over uncommon ports or high entropy HTTP/S connections. Dados: WinEventLog:Sysmon (EventCode=3, 22), WinEventLog:Sysmon (EventCode=1), WinEventLog:Microsoft-Windows-Windows Defender/Operational (Unusual external domain access).
  9. T1095 Non-Application Layer Protocol — Anomalous use of ICMP or UDP by non-network service processes for data exfiltration or remote control, especially if traffic bypasses proxy infrastructure or shows unusual flow patterns. Dados: WinEventLog:Sysmon (EventCode=3, 22), NSM:Flow (ICMP/UDP traffic (Wireshark, Suricata, Zeek)).
  10. T1136.001 Local Account — Adversary uses built-in tools like 'net user /add', PowerShell, or WMI to create a local user. Sequence: Account creation event (4720) follows process creation of a suspicious executable (e.g., powershell.exe or net.exe). Dados: WinEventLog:Security (EventCode=4720), WinEventLog:Sysmon (EventCode=1).
  11. T1552.001 Credentials In Files — Correlated file access to insecure credential files (e.g., *.env, *.xml, *.ps1) followed by suspicious process execution or authentication using retrieved credentials. Detected through Sysmon logs and Windows Security Event logs. Dados: WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=1), WinEventLog:Security (EventCode=4624, 4648).
  12. T1027 Obfuscated Files or Information — Correlates script execution or suspicious parent processes with creation or modification of encoded, compressed, or encrypted file formats (e.g., .zip, .7z, .enc) and abnormal command-line syntax or PowerShell obfuscation. Dados: WinEventLog:Security (EventCode=4688), WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=1).

13. Limites e confiança

  • O ATT&CK registra o que foi relatado publicamente, não tudo o que o grupo faz. Ausência de uma técnica não prova que o grupo não a usa.
  • Sobreposição de TTP não é atribuição. Muitas técnicas são compartilhadas entre grupos e com red teams. Use a assinatura comportamental como hipótese, junto com infraestrutura, malware e contexto.
  • Cobertura de detecção refere-se ao catálogo público Detection Rules, não ao seu ambiente: confira se a telemetria necessária chega ao seu SIEM.
  • Ligações marcadas como inferidas (EVTX por palavra-chave, relatórios por nome) devem ser verificadas.
