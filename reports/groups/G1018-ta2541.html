2. Quem é

TA2541 is a cybercriminal group that has been targeting the aviation, aerospace, transportation, manufacturing, and defense industries since at least 2017. TA2541 campaigns are typically high volume and involve the use of commodity remote access tools obfuscated by crypters and themes related to aviation, transportation, and travel.

9. Hipóteses de hunting

Se TA2541 estiver no seu ambiente, estas são as perguntas a fazer aos seus dados (fontes de log segundo as estratégias de detecção do MITRE ATT&CK).

  1. T1055.012 Process Hollowing — Detects adversary use of suspended process creation, using the CREATE_SUSPENDED flag via CreateProcess, followed by unmapping the memory of the child process (NtUnmapViewOfSection) and replacing it with malicious code via VirtualAllocEx/WriteProcessMemory,… Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=10), WinEventLog:Sysmon (EventCode=8).
  2. T1568 Dynamic Resolution — Correlate high-frequency or anomalous DNS query activity with processes that do not normally generate network requests (e.g., Office apps, system utilities). Detect pseudo-random or high-entropy domain lookups indicative of domain generation algorithms (DGAs). Dados: WinEventLog:Sysmon (EventCode=3, 22), WinEventLog:Sysmon (EventCode=1).
  3. T1016.001 Internet Connection Discovery — Execution of utilities (e.g., ping, tracert, Test-NetConnection) or scripted methods to test Internet connectivity by interacting with external IPs/domains. Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:PowerShell (EventCode=4103, 4104, 4105, 4106), WinEventLog:Security (EventCode=5156, 5157).
  4. T1027.015 Compression — Monitors for compression tool usage (e.g., 7zip, WinRAR, MakeCab) that follows or precedes file modification, suspicious file types (e.g., .exe, .dll) being compressed, or dropped from self-extracting archives followed by immediate execution. Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=11).
  5. T1573.002 Asymmetric Cryptography — Processes not typically associated with encryption loading asymmetric crypto libraries (e.g., rsaenh.dll, crypt32.dll) and subsequently initiating outbound TLS/SSL connections with abnormal certificate chains or handshakes.   6. T1055 Process Injection — Detects process injection by correlating memory manipulation API calls (e.g., VirtualAllocEx, WriteProcessMemory), suspicious thread creation (e.g., CreateRemoteThread), and unusual DLL loads within another process's context. Dados: WinEventLog:Sysmon (EventCode=10), WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=7).

12. Limites e confiança

  • O ATT&CK registra o que foi relatado publicamente, não tudo o que o grupo faz. Ausência de uma técnica não prova que o grupo não a usa.
  • Sobreposição de TTP não é atribuição. Muitas técnicas são compartilhadas entre grupos e com red teams. Use a assinatura comportamental como hipótese, junto com infraestrutura, malware e contexto.
  • Cobertura de detecção refere-se ao catálogo público Detection Rules, não ao seu ambiente: confira se a telemetria necessária chega ao seu SIEM.
  • Ligações marcadas como inferidas (EVTX por palavra-chave, relatórios por nome) devem ser verificadas.
