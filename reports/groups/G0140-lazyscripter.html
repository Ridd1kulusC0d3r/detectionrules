2. Quem é

LazyScripter is threat group that has mainly targeted the airlines industry since at least 2018, primarily using open-source toolsets.

Texto original do MITRE ATT&CK, em inglês.

9. Hipóteses de hunting

Se LazyScripter estiver no seu ambiente, estas são as perguntas a fazer aos seus dados (fontes de log segundo as estratégias de detecção do MITRE ATT&CK).

  1. T1071.004 DNS — Detects high-frequency or anomalous DNS queries initiated by non-browser, non-system processes (e.g., PowerShell, rundll32, python.exe) used to establish command and control via DNS tunneling. Dados: WinEventLog:Sysmon (EventCode=3, 22), NSM:Flow (dns.log).
  2. T1102 Web Service — Detects unusual outbound connections to web services from uncommon processes using SSL/TLS, particularly those exhibiting high outbound data volume or persistence. Dados: WinEventLog:Sysmon (EventCode=3, 22), NSM:Flow (SSL/TLS Inspection or PCAP).

T1218.005 Mshta — Detection of mshta.exe execution where command-line arguments reference remote or local HTA/script content (VBScript/JScript) followed by subsequent file creation, network retrieval, or process spawning that indicates payload execution outside standard… Dados: WinEventLog:Security (EventCode=4688), WinEventLog:Sysmon (EventCode=3, 22), WinEventLog:Sysmon (EventCode=11).
  4. T1588.001 Malware — Monitor for contextual data about a malicious payload, such as compilation times, file hashes, as well as watermarks or other identifiable configuration information.   5. T1036 Masquerading — Adversary renames LOLBINs or deploys binaries with spoofed file names, internal PE metadata, or misleading icons to appear legitimate. 12. Limites e confiança

  • O ATT&CK registra o que foi relatado publicamente, não tudo o que o grupo faz. Ausência de uma técnica não prova que o grupo não a usa.
  • Sobreposição de TTP não é atribuição. Muitas técnicas são compartilhadas entre grupos e com red teams. Use a assinatura comportamental como hipótese, junto com infraestrutura, malware e contexto.
  • Cobertura de detecção refere-se ao catálogo público Detection Rules, não ao seu ambiente: confira se a telemetria necessária chega ao seu SIEM.
  • Ligações marcadas como inferidas (EVTX por palavra-chave, relatórios por nome) devem ser verificadas.
