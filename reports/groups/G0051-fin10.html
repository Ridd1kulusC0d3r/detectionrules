2. Quem é

FIN10 is a financially motivated threat group that has targeted organizations in North America since at least 2013 through 2016. The group uses stolen data exfiltrated from victims to extort organizations.

Texto original do MITRE ATT&CK, em inglês.

10. Hipóteses de hunting

Se FIN10 estiver no seu ambiente, estas são as perguntas a fazer aos seus dados (fontes de log segundo as estratégias de detecção do MITRE ATT&CK).

  1. T1078.003 Local Accounts — Detects anomalous usage of local accounts to log into a system, especially accounts not typically used interactively or outside business hours. Dados: WinEventLog:Security (EventCode=4624, 4648), WinEventLog:Security (EventCode=4672).
  2. T1570 Lateral Tool Transfer — Correlate suspicious file transfers over SMB or Admin$ shares with process creation events (e.g., cmd.exe, powershell.exe, certutil.exe) that do not align with normal administrative behavior. Detect remote file writes followed by execution of transferred… Dados: WinEventLog:Security (EventCode=5140), WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=1).
  3. T1021.001 Remote Desktop Protocol — Remote Desktop (RDP) logon by a user followed by unusual process execution, file access, or lateral movement activity within a short timeframe. Dados: WinEventLog:Security (EventCode=4624, 4648), WinEventLog:Security (EventCode=4778, EventCode=4779), WinEventLog:Sysmon (EventCode=3, 22).
  4. T1033 System Owner/User Discovery — Adversary launches built-in system tools (e.g., whoami, query user, net user) or scripts that enumerate user account information via local execution or remote API queries (e.g., WMI, PowerShell). Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:PowerShell (EventCode=4103, 4104, 4105, 4106).
  5. T1070.004 File Deletion — Detects adversary behavior deleting artifacts (e.g., dropped payloads, evidence files) using native or external utilities (e.g., del, erase, SDelete). Detects deletion events correlated with unusual process lineage or timing post-execution. Dados: WinEventLog:Sysmon (EventCode=23), WinEventLog:Security (EventCode=4663, 4670, 4656), WinEventLog:PowerShell (EventCode=4103, 4104, 4105, 4106).
  6. T1078 Valid Accounts — Detection of compromised or misused valid accounts via anomalous logon patterns, abnormal logon types, and inconsistent geographic or time-based activity across Windows endpoints. Dados: WinEventLog:Security (EventCode=4624), WinEventLog:Security (EventCode=4776, 4625), WinEventLog:Sysmon (EventCode=1).
  7. T1053.005 Scheduled Task — Detects the creation, modification, or deletion of scheduled tasks through Task Scheduler, WMI, PowerShell, or API-based methods followed by execution from svchost.exe or taskeng.exe. Includes detection of hidden or anomalous scheduled tasks, especially those… Dados: WinEventLog:Security (EventCode=4698), WinEventLog:Security (EventCode=4702), WinEventLog:Sysmon (EventCode=1).
  8. T1547.001 Registry Run Keys / Startup Folder — Correlation of Registry key creation/modification events under known Run/Startup keys with new or unusual binary paths or script-based payloads. Multi-event detection includes registry modification followed by process execution from non-standard directories… Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=13, 14), WinEventLog:Microsoft-Windows-Shell-Core (New startup folder shortcut or binary placed in Startup directory).
  9. T1059.003 Windows Command Shell — Detects interactive or scripted abuse of cmd.exe, batch files, or shell invocation chains. Focuses on parent-child relationships (e.g., cmd.exe launched from unusual parents), anomalous command-line parameters, and chaining with discovery, credential access,… Dados: WinEventLog:Security (EventCode=4688), WinEventLog:Sysmon (EventCode=7), EDR:scriptblock (Process Tree + Script Block Logging).
  10. T1588.002 Tool — Monitor for contextual data about a malicious payload, such as compilation times, file hashes, as well as watermarks or other identifiable configuration information. In some cases, malware repositories can also be used to identify features of tool use… Dados: Malware Repository (None).
  11. T1059.001 PowerShell — Detects behavioral chains where PowerShell is launched with encoded commands, unusual parent processes, or suspicious modules loaded, potentially followed by network connections or child process spawning. Supports detection of both direct (powershell.exe) and… Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:PowerShell (EventCode=4103, 4104, 4105, 4106), WinEventLog:PowerShell (EventCode=400, 403).

13. Limites e confiança

  • O ATT&CK registra o que foi relatado publicamente, não tudo o que o grupo faz. Ausência de uma técnica não prova que o grupo não a usa.
  • Sobreposição de TTP não é atribuição. Muitas técnicas são compartilhadas entre grupos e com red teams. Use a assinatura comportamental como hipótese, junto com infraestrutura, malware e contexto.
  • Cobertura de detecção refere-se ao catálogo público Detection Rules, não ao seu ambiente: confira se a telemetria necessária chega ao seu SIEM.
  • Ligações marcadas como inferidas (EVTX por palavra-chave, relatórios por nome) devem ser verificadas.
