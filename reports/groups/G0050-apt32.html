2. Quem é

APT32 is a suspected Vietnam-based threat group that has been active since at least 2014. The group has targeted multiple private sector industries as well as foreign governments, dissidents, and journalists with a strong focus on Southeast Asian countries like Vietnam, the Philippines, Laos, and Cambodia. They have extensively used strategic web compromises to compromise victims.

10. Hipóteses de hunting

Se APT32 estiver no seu ambiente, estas são as perguntas a fazer aos seus dados (fontes de log segundo as estratégias de detecção do MITRE ATT&CK).

  1. T1216.001 PubPrn — Execution of PubPrn.vbs via cscript.exe using the 'script:' moniker to load and execute a remote .sct scriptlet file, bypassing signature validation and proxying remote payloads through a signed Microsoft script host. Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:PowerShell (EventCode=4103, 4104, 4105, 4106), WinEventLog:Sysmon (EventCode=3, 22).
  2. T1564.004 NTFS File Attributes — Suspicious use of NTFS file attributes such as Alternate Data Streams (ADS) or Extended Attributes (EA) to hide data. Defender perspective: anomalous file creations or modifications containing colon syntax (file.ext:ads), API calls like… Dados: WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=15).
  3. T1027.011 Fileless Storage — Detects abuse of fileless storage mechanisms such as Registry keys, WMI classes, and Event Logs used to stage payloads, scripts, or encoded content outside traditional files. Dados: WinEventLog:Security (EventCode=4657), WinEventLog:Application (WMI Object Creation Events).
  4. T1137 Office Application Startup — Office-based persistence via Office template macros, Outlook forms/rules/homepage, or registry-persistent scripts. Adversary modifies registry keys or Office application directories to load malicious scripts at startup. Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=13, 14).
  5. T1550.003 Pass the Ticket — Detects unauthorized Kerberos ticket injection by correlating service ticket (TGS - 4769) requests with absent corresponding account logons (4624) and prior Ticket Granting Ticket (TGT - 4768) activity. Highlights anomalous service ticket generation chains… Dados: WinEventLog:Security (EventCode=4769), WinEventLog:Security (EventCode=4768), WinEventLog:Security (EventCode=4624, 4648).
  6. T1552.002 Credentials in Registry — Defenders observe command-line executions or API-based registry reads targeting sensitive paths like HKLM or HKCU with keyword filters such as 'password', 'cred', or 'logon'. Typically performed by Reg.exe, PowerShell, custom binaries, or offensive tools such… Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=13, 14), EDR:hunting (Behavioral rule for registry enumeration under credential-related paths).
  7. T1222.002 Linux and Mac Permissions — Linux permission escalation behavioral chain: (1) Process creation of permission modification utilities (chmod, chown, chgrp, setfacl) with suspicious parameters indicating privilege escalation intent, (2) System call analysis revealing direct file metadata… Dados: auditd:SYSCALL (syscall in (chmod, fchmod, fchmodat, chown, fchown, fchownat, lchown, setxattr, lsetxattr, fsetxattr, removexattr, lremovexattr, fremovexattr)), auditd:PROCTITLE (proctitle contains chmod, chown, chgrp, setfacl, or attr with suspicious parameters (777, 755, +x, -R)), linux:osquery (process execution events for permission modification utilities with command-line analysis).
  8. T1036.003 Rename Legitimate Utilities — Execution of binaries where the on-disk filename does not match PE metadata such as OriginalFilename or InternalName. Often observed with renamed LOLBAS or system binaries like rundll32, powershell, or psexec. Dados: WinEventLog:Sysmon (EventCode=1), WinEventLog:Sysmon (EventCode=11), EDR:AMSI (None).
  9. T1071.003 Mail Protocols — Detects unauthorized use of SMTP/IMAP/POP3 by suspicious binaries (e.g., PowerShell, rundll32) to exfiltrate data or beacon via email, often bypassing proxy or content filters. Dados: WinEventLog:Sysmon (EventCode=3, 22), WinEventLog:Sysmon (EventCode=1), NSM:Flow (smtp.log).
  10. T1027.016 Junk Code Insertion — Detects the presence of executables with high NOP padding, unusually large binary size for their function, and follow-on execution or memory injection from such files, especially when originating from temp or user-space paths. Dados: WinEventLog:Sysmon (EventCode=11), WinEventLog:Sysmon (EventCode=10), WinEventLog:Sysmon (EventCode=1).
  11. T1608.004 Drive-by Target — If infrastructure or patterns in the malicious web content utilized to deliver a Drive-by Compromise have been previously identified, internet scanning may uncover when an adversary has staged web content for use in a strategic web compromise. Much of this… Dados: Internet Scan (None).

T1072 Software Deployment Tools — Detects SCCM, Intune, or remote push execution spawning scripts or binaries from SYSTEM context or unusual consoles (e.g., cmtrace.exe launching PowerShell or cmd.exe). 13. Limites e confiança

  • O ATT&CK registra o que foi relatado publicamente, não tudo o que o grupo faz. Ausência de uma técnica não prova que o grupo não a usa.
  • Sobreposição de TTP não é atribuição. Muitas técnicas são compartilhadas entre grupos e com red teams. Use a assinatura comportamental como hipótese, junto com infraestrutura, malware e contexto.
  • Cobertura de detecção refere-se ao catálogo público Detection Rules, não ao seu ambiente: confira se a telemetria necessária chega ao seu SIEM.
  • Ligações marcadas como inferidas (EVTX por palavra-chave, relatórios por nome) devem ser verificadas.
